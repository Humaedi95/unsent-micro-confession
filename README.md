This entry writes a single unsent micro-confession to `/output/entry.txt`: a "To:" line naming who the message was meant for, followed by the one line that was typed and never sent — a quiet, specific confession of guilt about a voicemail from a missed call that has never been played, kept in drafts because hearing it would mean facing the night it came from.
